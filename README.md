# confidence-web-demo 

This repository demonstrates how Confidence can be used in a simple project.

## Examples

### Next.js
See the Next.js demo: [nextjs/](./nextjs/)

### Java Spring Boot
See the Java Spring Boot demo: [java/](./java/)

## Local development

Each demo runs independently. See the linked READMEs above for full setup details.

### Next.js
```bash
cd nextjs
yarn install
yarn dev
```
Then open [http://localhost:3000](http://localhost:3000).

### Java Spring Boot
```bash
cd java
mvn spring-boot:run
```
The API starts on [http://localhost:8080](http://localhost:8080).
